# Зонд 0.0.2: что проверить в игре (10-15 минут)

Распакуй zip в `_forever_\Interface\AddOns` (папка `FullHealthForever`), зайди персонажем.
Full Mana Forever можно не выключать. В сумках желательно: зелье здоровья, камень здоровья
(если есть варлок), бинт, зелье маны.

## Окно на экране (`/fhf probe watch`)
- Строки 1-3: здоровье, проценты (`pct false / true`), входящий хил и щиты (числа видны, даже если
  секретные: игра сама их рисует).
- Квадраты справа:
  - белый (строка 1): здоровье ниже 50 %;
  - **красный / оранжевый (строка 4): здоровье + летящий хил не выше 50 % / 80 %.** Главный опыт;
  - зелёный (строка 7): свой защитный КД готов.
  Яркий = да, тусклый = нет.
- Строка 6: угроза (0 нет, 3 моб бьёт тебя) и полученный урон в секунду.
- Полосы внизу: здоровье сейчас / 2 с назад / входящий хил / щиты.

## 1. Соло, вне боя (2 мин)
- [ ] `/fhf probe`.
- [ ] `/fhf probe watch 30`, скрин окна.

## 2. Соло, в бою (5 мин)
- [ ] Макрос `/fhf probe`, нажми **в бою**.
- [ ] `/fhf probe watch 120`, дерись:
  - дай мобу опустить тебя ниже 50 %: загорелись ли белый и красный квадраты? Скрин;
  - выпей зелье здоровья; потом зелье маны (или наоборот), смотрим общий кулдаун;
  - нажми свой защитный КД (строка 7): погас ли зелёный квадрат и вернулся ли, когда КД прошёл;
  - после боя наложи бинт.
- [ ] Если умрёшь (не обязательно): после смерти `/fhf probe`, там отчёт о смерти.

## 3. С хилером (5 мин)
- [ ] `/fhf probe` в группе.
- [ ] `/fhf probe watch 120`, хилер кастует **долгий** хил на тебя, когда у тебя меньше 50 %
      (Greater Heal / Healing Wave / Holy Light), потом HoT (Renew / Rejuvenation) и щит
      (Power Word: Shield).
      **Скрин во время каста хилера:** гаснет ли красный квадрат, пока хил ещё летит?
      Меняется ли `pct true`?

## 4. В подземелье (если получится, 2 мин)
- [ ] Внутри подземелья: `/fhf probe` вне боя и макросом в бою.

## 5. Прислать
- [ ] `/reload` (или выйти), потом пришли файл
      `WTF\Account\<аккаунт>\SavedVariables\FullHealthForever.lua` и скрины.
      В файле только технические строки, без имён (юниты как party1; названия заклинаний и
      предметов из игры).

# Зонд 0.0.3: что проверить в игре (10 минут)

0.0.2 уже ответил на многое (см. `docs/notes.md`, "Results"). Здесь только то, что осталось.
Распакуй zip поверх старого (папка `FullHealthForever`). В сумках: зелье здоровья, **зелье маны**,
бинт.

## Окно (`/fhf probe watch 300`)
- белый квадрат: здоровье ниже 50 %;
- **красный: ОПАСНО** = здоровье ниже 50 % И летящий хил не поднимет выше 50 %;
- **оранжевый:** летящий хил дотянет выше 50 % (флаг игры сам по себе);
- зелёный: свой КД готов (теперь берётся заклинание с настоящим КД, у жреца, например,
  Psychic Scream).
Ярко = да, тускло = нет.

## 1. Соло, жрец (5 мин) — главный опыт
- [ ] Вне боя один раз `/fhf probe` (снимок вне боя ещё не было).
- [ ] `/fhf probe watch 300`, бой с мобом:
  - опустись ниже 50 %: белый и **красный** яркие, оранжевый тусклый? Скрин;
  - начни **долгий хил на себя** (Heal / Greater Heal), который поднимет выше 50 %:
    **во время каста** красный тускнеет, оранжевый загорается? **Скрин во время каста.**
  - то же с маленьким хилом, который выше 50 % НЕ поднимет: красный должен остаться ярким;
  - нажми Psychic Scream (или другой КД): в чате появится строка `cd ... isActive false -> true`;
  - выпей зелье здоровья (зелье маны не пей): после боя в чате будет строка про кулдаун зелья
    маны — `dur=120` значит, кулдаун общий.
- [ ] После боя подожди 2 секунды: появится блок `after fight:`.

## 2. В группе / в подземелье (когда получится)
- [ ] То же наблюдение, хилер кастует на тебя долгий хил, когда у тебя меньше 50 %.
- [ ] В подземелье: `/fhf probe` вне боя и макросом в бою.

## 3. Прислать
- [ ] `/reload`, файл `WTF\Account\<аккаунт>\SavedVariables\FullHealthForever.lua` и скрины.

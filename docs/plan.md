## 2. MVP 0.1 (размер M)

Цель: одна честная иконка «спасайся» и полоса, без ложных «жми».

1. **Полоса здоровья** (рядом с FMF по умолчанию): здоровье, летящий хил (свой / чужой одним
   цветом), щиты; тень «2 с назад» (выключаемая). Текст здоровья (секрет форматирует игра).
2. **Ряд иконок** (камень, зелье, бинт, свой защитный КД — по классу и роли): серые, когда не
   готовы (кулдаун предмета / объект длительности), **яркие только при «опасно»**:
   здоровье ниже порога роли **и** летящий хил не поднимет выше порога.
   - Порог (по опыту агентов, настраивается): соло / ДД / хилер при агро на тебе 35 %, без агро
     25 %; танк 30 % (+ своя «линия одного удара» — потом).
   - Агро (читается) выбирает порог: два калькулятора, два набора кривых.
   - Бинт: только без агро и вне Recently Bandaged (свой таймер 60 с от своего каста;
     «Полевая медицина» вне подземелий — по таланту).
   - Паладин-танк: Divine Shield / Divine Protection / Blessing of Protection **не подсвечивать**.
   - Порядок для хилера: камень, свой КД, зелье последним.
3. **Значок угрозы**: ДД / хилер / соло — «моб на тебе»; танк — «цель бьёт не тебя».
4. **`/fhf hold`**: как `/fmf hold`, гасит подсказки до конца следующего боя (фазы, где стоят
   низко нарочно).
5. **Только в бою** по умолчанию; настройки, профили, 9 языков, подсказки у кнопок — как в FMF.
6. **Не делаем**: тексты «жми стену», вспышки на весь экран, звук по умолчанию, «подожди,
   отхилят» как отдельную подсказку.

Перед 0.1 в игре: свой КД в бою через объект длительности; общий КД зелий; один бой в группе с
хилером; одно подземелье (угроза, флаг калькулятора).

## 4. Архитектура

**Отдельный аддон** (рекомендую), код из FMF копируется и упрощается, общих библиотек нет.

| Вариант | Плюсы | Минусы |
| --- | --- | --- |
| Отдельный аддон (рекомендую) | свой релиз, свои ошибки не ломают FMF; можно поставить без FMF | копия кода (профили, настройки, мок) живёт отдельно |
| Модуль внутри FMF | один аддон, один блок | FMF «про ману»; риск сломать стабильный аддон; страница CurseForge одна |
| Общая библиотека | один код | правило «без библиотек»; две версии на руках у игроков |

Связь с FMF: **через игру, не через Lua**: оба читают кулдауны предметов сами; «опасно» передать
нельзя (это прозрачность). Общий порог Life Tap — только как настройка в FMF.

Файлы (порядок TOC, как сделано в 0.1): `Locale.lua` (генерируется `tools/locale_gen.py`) →
`Data.lua` (ID, проверяемые игрой при запуске) → `Profiles.lua` (из FMF) → `Engine.lua` (кривые,
калькулятор, вложенные прозрачности, линия, готовность) → `HUD.lua` (полоса, хил, щиты, тень,
слои иконок, значок агро) → `Core.lua` (настройки, события, такт, команды) → `Options.lua`.
`Probe.lua` удалён в 0.1.

Ключи настроек (профиль): `role` (auto / tank / healer / dps), `thrAggro` (35), `thrNoAggro`
(25), `thrTank` (30), `groups` (stone, potion, bandage, defensive), `shadow` (true), `shadowSec`
(2), `onlyCombat` (true), `showIn` (solo / party / raid), `threatIcon` (true), `point`, `scale`.
Аккаунт: `language`, `debug`, `seenVersion`, `dbVersion`.

## 5. Риски и «чего не делать»

- **Ложное «жми»** под чужим HoT'ом, под щитом жреца с другой стороны, во время Ice Block / Vanish
  / Feign Death, при агро на пете. Часть закрывается своими кастами (свой Ice Block — знаем),
  часть — нет: порог ниже без агро, и только иконки, никакого текста «жми».
- **Опасность не видна Lua**: нельзя звенеть «по опасности», нельзя логировать её для отчётов.
  Звук возможен только по событиям, которые Lua видит (агро, удар).
- **Подземелья / рейды не проверены**: угроза и флаг калькулятора могут стать секретными иначе.
- **Конкуренты** (DontDie, Pleeb, Low Health Helper, Healthstone Auto) и встроенный красный край:
  без хила и угрозы мы — «ещё один порог». Отличие держится на флаге калькулятора и агро.
- **Общий КД зелий**: если он общий, зелье здоровья отнимает зелье маны: подсказать хилеру
  «зелье последним» обязательно.
- Не повторять ошибку из задания: **Dark Pact** в классике берёт ману у пета, здоровье не тратит.

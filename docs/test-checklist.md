# Full Health Forever 0.1 – что проверить в игре

Распакуй zip в `_forever_\Interface\AddOns` (папка `FullHealthForever`; старую с зондом удали).
В сумках: камень здоровья (если есть варлок), лечебное зелье, бинт, зелье маны.

## 1. Первый вход (2 мин)
- [ ] В чате одна строка приветствия, ошибок Lua нет (`/console scriptErrors 1`).
- [ ] `/fhf config`: окно открывается, рамка видна, пока окно открыто. Наведи мышь на каждую
      кнопку и галочку: у всех есть подсказка. Перетащи окно за заголовок.
- [ ] `/fhf unlock`: рамка с синим фоном, перетащи её, `/fhf lock`.
- [ ] В иконках: камень / зелье / твои защитные (жрец: Отчаянная молитва, если она есть) / бинт.

## 2. Соло, бой (5 мин)
- [ ] Рамка появляется при начале боя, исчезает после.
- [ ] Выше 35 %: иконки тусклые (готовы), не яркие.
- [ ] Ниже 35 % без хила: зелье и камень **ярко горят** с красной рамкой. Бинт — нет (моб на тебе).
- [ ] Ниже 35 %, начни долгий хил на себя, который поднимет выше 35 %: **во время каста иконки
      гаснут**. Скрин.
- [ ] Выпей зелье: оно становится серым (кулдаун), камень горит дальше.
- [ ] Тень: когда тебя бьют, за зелёной полосой видна тёмно-красная (где здоровье было 2 с назад).
- [ ] Защитный КД: нажми его в бою: иконка становится серой и не горит, пока КД идёт. **Главный
      непроверенный пункт**: работает ли это в бою.
- [ ] `/fhf hold` перед боем: в бою ничего не горит, на ряду надпись «ПАУЗА»; после боя «Подсказки
      снова работают».

## 3. После боя
- [ ] Бинт: без моба на тебе и ниже 25 % (или подними линию в настройках) — горит; после
      наложения 60 с не горит.
- [ ] Зелье маны и зелье здоровья: после того как выпил зелье здоровья, серая ли иконка зелья маны
      в FMF (общий кулдаун)?

## 4. Группа / подземелье (когда получится)
- [ ] Роль из группы: `/fhf status` показывает role=healer / tank / dps.
- [ ] Значок «АГРО» слева от полосы, когда моб переключился на тебя (не танку).
- [ ] Танк: значок, когда цель бьёт не тебя.
- [ ] На боссе (ограничение Encounter): иконки и полоса работают так же.

## 5. Прислать
- [ ] Скрины, `/fhf status` (строки из чата) и ошибки Lua, если были.

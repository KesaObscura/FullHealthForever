# Исследование перед планом (7 ноября 2026)

Источники: документация API клиента Forever (публичное зеркало исходников интерфейса Blizzard,
ветка `forever`, сборка 1.60.1 (70862)), открытые аддоны для Forever и ретейла, гайды по Forever.
Факты с пометками источника лежат в `docs/notes.md`. **В игре ничего из этого не проверено**,
кроме того, что уже проверено для Full Mana Forever. Для проверки — зонд 0.0.2
(`docs/probe-test.md`).

## Главное

1. **Forever — это ретейловый клиент 12.x с секретами.** В нём есть всё, что Blizzard сделала
   для аддонов в 12.0: калькулятор входящего хила, «да/нет» в прозрачность, объекты длительности
   с кривыми, встроенный счётчик урона, отчёт о смерти, менеджер кулдаунов.
2. **Входящий хил и щиты показать можно** (документация + аддоны на Forever уже рисуют). HoT'ы
   в входящий хил не входят: только касты, которые летят (два аддона пишут одно и то же).
3. **Решение «здоровье + летящий хил ниже X %» — возможно, но не точно.** У калькулятора есть
   флаг «хил упёрся в предел» (`clamped`), и игра умеет превратить секретное «да/нет» в
   прозрачность иконки. Предел задаётся числом overflow (у Blizzard 1.05). Если игра примет 0.5,
   флаг будет значить «здоровье + хил выше 50 %», и иконку зелья можно гасить именно тогда, когда
   хилер успевает. Зонд проверяет (красный и оранжевый квадраты).
4. **«Твой аргумент predicted» не про хил.** В документации это `usePredicted`, как у
   `UnitHealth`: предсказание клиентом своего же значения. Зонд всё равно сравнит.
5. **Урон за 2 / 10 / 50 с:**
   - числом в бою — скорее нет: `UNIT_COMBAT` по документации отдаёт урон секретом; один аддон
     пишет, что хил на тебе читается. Зонд покажет;
   - картинкой — да: полоса «здоровье N секунд назад» рядом с текущей (разница = урон);
   - встроенный счётчик урона даёт «урон в секунду за бой» текстом в бою и числами после боя.
6. **Угроза для игрока, по документации, обычно не секретна.** «Моб переключился на тебя» —
   сильный сигнал опасности для ДД и соло, «потерял агро» — для танка. Зонд проверит.
7. **Свои защитные КД в бою:** у кулдауна поле `isActive` («на КД») помечено как никогда не
   секретное. Если это правда, «стена готова» читается в бою без своего счёта. Есть и запасной
   путь через объект длительности и кривую. Это пригодится и Full Mana Forever (сейчас он в бою
   кулдауны не спрашивает). У игры есть свой список «больших защитных» (`AuraIsBigDefensive`).
8. **В подземельях и рейдах ограничений больше** (отдельный тип ограничения «Map»). FMF тестировали
   в открытом мире; зонд надо прогнать и внутри подземелья.

## Конкуренты и соседи

| Аддон | Что делает | Чем мы отличаемся |
| --- | --- | --- |
| Встроенное в игру | Красный край экрана ниже 35 %; голосовые оповещения и «пульс» здоровья (доступность) | Порог свой и по роли, учёт хила, нужная кнопка |
| DontDie / HealHelper | Камень и зелье здоровья ниже порога, с клавишей с панели | Они: «ниже X %». Мы: «ниже X % и хилер не успевает» |
| PleebPot, Pleeb Defensive Reminders | Пороги для камня, зелья и КД из менеджера кулдаунов (ретейл) | То же |
| Low Health Helper | Камень, зелье, свои хилы ниже 35 % («ограничение API») | У FMF руны работают с любым порогом через кривую: их 35 % — ограничение способа, не игры |
| Healthstone Auto | Камни здоровья, сделан для Forever | Узко |
| Forever Unit Frames, oUF, Better Heal Bars | Рамки с входящим хилом, щитами, угрозой | Мы не рамка: подсказка «жми / жди» |

Вывод: просто полоса с хилом уже есть у рамок; голый порог «ниже X %» есть у четырёх аддонов и у
самой игры. Наше место — **решение с учётом хила, угрозы и роли**. Если трюк с overflow не
сработает, главное отличие пропадает, и аддон станет «ещё одним порогом» — это решать после зонда.

## Приёмы, которые можно взять (идеи, не код: аддоны под GPL)

- Полосы входящего хила и щитов, сцепленные якорями: сложение делает раскладка игры, не Lua.
- Скрытая полоса шириной в 1 единицу вокруг порога: она либо пустая, либо полная — сравнение
  секрета с числом без чтения (так один аддон отмечает перехил).
- `SetAlphaFromBoolean` для секретных «да/нет»: в радиусе, перехил, щит больше недостающего.
- `C_StringUtil.TruncateWhenZero`: текст, который пустеет при нуле (щит есть / нет), без сравнения.
- Свои HoT'ы по своим кастам (как Evocation в FMF); их конец в бою — через `AuraContainer`.
- Тесты на моке с секретами, которые падают при сравнении (у нас уже так).

## Что изменилось в Forever и важно для нас (гайды, проверить в игре)

- Зелья здоровья делает Первая помощь; все ранги — общий кулдаун 2 мин (и, скорее всего, общий с
  зельями маны: зонд проверит — тогда FHF и FMF должны знать друг о друге).
- Бинты как в Classic, Recently Bandaged 60 с; талант Первой помощи сокращает вне подземелий.
- Новое: припарки (болезни) и жгуты (кровотечение) — только вне боя, общий кулдаун 1 мин.
  Для подсказки «прожми в бою» не годятся; для «после боя» — может быть.
- Классовые правки: Shield Wall — талант режет кулдаун; Sacred Duty сокращает Forbearance;
  Barkskin в формах.

## Где мы можем ошибиться (риски уже сейчас)

- Если `clamped` при overflow < 1 игра не примет или поведёт себя иначе, решения «с учётом хила»
  нет; останется показ полос и решения по одному здоровью (как у конкурентов) плюс угроза.
- Входящий хил не видит HoT'ы: «подожди, тебя отхилят» не сработает под HoT'ами друида / жреца —
  подсказка будет говорить «жми», хотя HoT дотянет. Ложное «жми» при HoT'ах — риск.
- В рейдах и подземельях ограничений больше: то, что работает соло, может не работать там.
